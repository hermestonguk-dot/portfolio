# COMP63301 Data Engineering Concepts Coursework Evidence

This folder contains four COMP63301 coursework/lab submissions.


## Labs

- `01-sqlite-trip-cleaning`: SQLite data-cleaning and trip-duration queries using `coursework2.db`.
- `02-csv-mongodb-sqlite-integration`: CSV, MongoDB, SQLite, and journey-time integration using traffic, weather, and route-distance data.
- `03-sqlite-biodiversity-analysis`: Pandas and SQLite analysis of Sites of Biological Importance data.
- `04-snakemake-carbon-pipeline`: Snakemake ETL pipeline for Global Carbon Project fossil CO2 emissions data.
