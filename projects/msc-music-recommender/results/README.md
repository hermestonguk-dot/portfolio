# Saved Results

These files are small exports from the completed MSc experiments:

- `dataset_stats.json`: dataset and split counts.
- `final_test_layers0_1_dim128_1500/test_aggregate.csv`: matched model
  comparison across three seeds.
- `smooth_xquad_comparison_validation_layer1_dim128_converged/`: validation
  comparison and the selected reranking weight.
- `smooth_xquad_comparison_test_layer1_dim128_converged/`: final test
  comparison and its run configuration.

The original model checkpoints and processed dataset are excluded from this
repository. The figures in `../report_evidence/figures/` were generated from
the same experiment record.
